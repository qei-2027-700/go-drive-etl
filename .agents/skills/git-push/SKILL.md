# git-push スキル

**まず `docs/workflows/git.md` の「3. リモートへのプッシュ」セクションを Read ツールで読んでから、記載された手順に従って実行してください。**

このスキルは、現在のブランチをリモートの `origin` に安全にプッシュします。追跡ブランチの有無による分岐・禁止事項はそのドキュメントに記載されています。
